## Lancer le projet en local

Aucune dépendance ni build requis — site statique.

```bash
git clone https://github.com/BLakara2/portfolio.git
cd portfolio
# ouvrir index.html dans un navigateur,
# ou servir le dossier :
npx serve .
```
